# Nuray Equestrian — website

Fast, zero-dependency static site (plain HTML/CSS/JS, generated by a tiny Node script). No framework and a few KB of CSS/JS, so it is quick and can be hosted anywhere (Netlify, Cloudflare Pages, GitHub Pages, cPanel).

## Pages
Home · About · Lessons · Training · Boarding · Horses · Events · Gallery · Team · FAQ · Contact/Booking · Privacy · 404, plus `sitemap.xml`, `robots.txt`, SEO/OpenGraph/JSON-LD.

## Commands
```
npm run build   # generates ./dist
npm run serve   # build + preview at http://localhost:4173
```
Deploy `dist/`. For a GitHub Pages project site: `BASE=/nuray_equest/ npm run build`.

## Customising
- Contact details / URL: `src/config.mjs`
- Copy & layout: `src/pages.mjs`; header, footer, SEO: `src/layout.mjs`
- Colours & type: CSS variables at the top of `assets/css/style.css` (from the brand board)
- Logo: replace `assets/img/logo.svg` (light backgrounds) and `assets/img/logo-light.svg` (dark/hero). Current files are placeholders.
- Photos: put files in `assets/img/photos/` (`.webp`/`.jpg`/`.png`); branded placeholders show until then. Names: `hero, about, about-hero, lesson, training, boarding, events, <page>-hero, ride1-3, facility1-3, horse-<name>, team-1..4, map`, plus `assets/img/og.jpg` (1200×630).
